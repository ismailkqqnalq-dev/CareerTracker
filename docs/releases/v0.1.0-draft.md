# CareerTracker v0.1.0 — release description draft

**CareerTracker is a prototype, not production-ready software.** This release provides a FastAPI career CRM backend and an early React MVP for reviewing and matching skill suggestions. Publishing the container does not deploy a hosted service.

## Run the backend image

Generate a fresh JWT key locally and provide it, together with `DATABASE_URL`, through your runtime's secret/configuration mechanism. Do not put secrets in the image or commit them.

```sh
python -c "import secrets; print(secrets.token_hex(32))"
docker pull ghcr.io/ismailkqqnalq-dev/careertracker@sha256:a2d887dfcbab46f30e253c1ca7d69573940228c59ea67cc9ad28131b930fe4b2
```

Required runtime settings: `JWT_SECRET_KEY` (the generated key), `DATABASE_URL` (your database connection), `APP_ENV=production`, and `REGISTRATION_ENABLED=false` unless open registration is intentional. Registration is closed by default unless development mode or an explicit registration override is enabled. Apply Alembic migrations deliberately before use.

## Known limitations

- Rate limits are process-local and are not shared among multiple server workers.
- The React interface is a limited skill-suggestion MVP, not a complete CRM interface; its token is held in sessionStorage.
- List pagination and general create/update field-length limits are not implemented yet.
- Account deletion and user-data export are not available.
- Production security headers and a Content Security Policy are not configured.
- OCR is optional and extracts text only; OCR output can be imperfect. The job-analysis matcher is rule-based, not a trained ML model.
- This project is a portfolio prototype; review and harden deployment, backups, monitoring, and operational controls before exposing it to users.
